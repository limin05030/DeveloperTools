# windows 版本安装说明

下载 `DeveloperTools.exe`，免安装直接运行。

# macOS 版本安装说明

下载 `DeveloperTools-macos.tar.gz`，解压后得到 `DeveloperTools.app
`，然后将 `DeveloperTools.app` 复制到 `/Applications` 目录中。

第一次启动时，由于 app 的签名问题，会导致被系统阻止，需要手动允许：
